[`auto_otp`](https://pub.dev/packages/auto_otp) is a Flutter package that allows Android apps to automatically retrieve and parse OTPs from SMS using the **SMS User Consent API**.

- 🚀 Simple 1-liner integration  
- 🔐 No SMS read permission required  
- 🛠️ Works seamlessly with most OTP-based flows  

This package is fully open-source and maintained by [@nikb7](https://github.com/nikb7). Contributions and feedback are welcome!
